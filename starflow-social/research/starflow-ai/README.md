# Starflow AI Lab｜iPhone 零预算自主研发起点

> 状态：研究原型（Research Prototype）；不是基础视频生成模型，也不涉及付费 API 或上线部署。

## 我们要研发什么

长期目标：逐步研发 Starflow 自有视频生成与控制技术，包括图生视频、动作控制、身份一致性、视频质量评测、超分辨率及补帧。

必须区分三类资产：
1. **自研代码**：团队原创编写的评测、处理、训练流程与未来算法。
2. **开源权重/模型微调**：在允许的许可证下使用第三方权重，不得把底座冒充为从零自研。
3. **第三方 API**：请求别人的模型，通常有用量及收费约束，与模型所有权无关。

## 今日第一个真正可执行的实验

打开本目录的 `motion-lab.html`。它是一个**离线网页原型**，使用手机/浏览器中的视频解码与 Canvas：
- 选择 iPhone 相册导出的视频文件；
- 抽取最多 12 个时间采样帧，在较低分辨率下计算**相邻采样帧像素平均绝对差（0–255）**；
- 展示采样详情、首尾采样图；不上传视频、不使用任何 API、不需 GPU。

它**不是**动作识别、AI 视频生成、人物复刻或专业质量评分：运动量大、镜头切换、光照变化都会提高像素差。这个实验的目的只是学会视频帧读取与可复现的计算，为后续时序一致性评测奠定基础。

由于 GitHub 浏览器预览源代码不会执行 HTML，实际运行时请使用可靠的静态网站托管（例如经审核后将此文件作为 Starflow 静态资源部署），或将它下载并用支持本地 HTML 的浏览器/代码工具打开。**本分支目前未部署上线。** 不要为了运行该实验购买 API。

## iPhone 操作顺序

1. 在手机 Safari 登录 GitHub，打开对应研究 PR。
2. 查看 `starflow-social/research/starflow-ai/` 的 `README.md` 和 `motion-lab.html`。
3. 给手机相册准备一段你自己拍摄或获得授权的 5–10 秒视频，留待在静态网页运行后测试。
4. 点击实验页面「选择视频」和「开始本地分析」，记录采样分数、视频长度、分辨率，以及你观察到的画面变化。
5. 如不能打开该 HTML，请先不要充值或购买服务器：需要先确认免费部署渠道并完成安全审核。

## 30 天研究路线（不承诺 0 元 GPU）

- **第 1 周**：完善移动端视频读取；建立基准测试素材、实验记录格式；补充基本测试。
- **第 2 周**：做更可靠的运动与场景切换判别（仍属视频分析，非生成）。
- **第 3 周**：比较获许可开源视频生成框架；确认版权/算力/VRAM/使用限制。仅在确有免费 GPU 配额时运行。
- **第 4 周**：在有资源时尝试小模型推理或参数高效微调；无免费 GPU 时继续本地评测及数据准备。

## 约束与注意

- **预算：0 元**。默认禁止调用 Fal 等付费推理服务；Starflow 原有 AI Studio 的付费 API 功能保持关闭状态。
- iPhone 不适合训练大型视频生成模型；免费云 GPU 有排队、时限、限额和不可用风险。
- **4K/120FPS** 是长期输出处理目标，不是本实验具备的能力，也不应误称原生生成。
- 不上传未授权的人脸/参考视频；不提交令牌、密钥、私人素材到公开 GitHub 仓库。
- 本研究分支不修改现有生产网站。没有经过代码审查、测试和用户确认，不应合并或部署。
