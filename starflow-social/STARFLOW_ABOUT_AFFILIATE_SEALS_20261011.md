# Starflow 关于此账号 · 双徽章与组织关联修复

- 对有效金色或灰色认证的组织，其已接受的「组织类附属账号」显示关联组织衍生的认证徽章及独立组织小头像；小头像链接到所属组织主页。
- 如果附属账号已独立取得认证，优先显示自身正式认证记录，避免重复显示金标。
- 「已验证」信息明确区分独立审批的时间与组织附属关系生效时间；没有为 `@starflow` 创建假的独立审批记录。
- 若关联解除、组织认证被撤销，显示层的衍生徽章自动不再满足生效条件。
- 账号加入时间、名称变更和 IP 地区信息均沿用原数据，不触碰用户或数据库。
- 变更范围仅为原有账号详情页面组件和该页面 CSS。首页、认证徽章 SVG 和其他页面均不修改。

上传本 ZIP 时仓库根目录目标文件名为 `starflow-release.zip`，GitHub Workflow 会解压到 `starflow-social/...` 并执行生产构建。
