# Starflow AI — 头像封面预览交互修复包（2026-10-11）

参照用户提供的 X iOS 录屏：正常个人主页无永久相机叠加层；点击头像或封面进入大图预览，只有本人才能在预览底部看到更换图片的操作。点击关闭或空白处退出预览，支持 Escape。

- 保留设置页已有图片管理功能作为备用入口；不改动账户/帖子/互动/数据库/存储权限。
- 点击头像：查看无相机遮挡的圆形大图。本人预览底部显示「更换头像」。
- 点击封面：查看大图或默认渐变；本人预览底部显示「更换封面」。
- 游客访问其他人的主页只看照片，不显示编辑入口。
- 上传仍使用原组件的安全校验、iPhone 图片压缩、Supabase Storage + RLS 及自动刷新。
- 不新增数据库迁移；不调整已正常工作的发帖或关注模块。

## 部署
将此压缩包作为仓库根目录 `starflow-release.zip` 上传覆盖旧文件，触发 `Starflow ZIP Auto Update`。注意 iPhone 自动生成的后缀 `2.zip` 或 `.zip.zip` 会导致仅代码检查而不能应用新代码。

## 验收
使用 iPhone Safari 进入自己的主页，未点击时头像不能出现相机图标；点击头像出现大图预览并有更换按钮；返回后点封面出现全屏预览和更换按钮；点击更换完成上传，刷新后照片持久显示；访问他人主页不出现编辑选项。

本地进行 TSX 语法与 ZIP 结构检查；GitHub/Cloudflare 构建和浏览器操作须上线后核验。
