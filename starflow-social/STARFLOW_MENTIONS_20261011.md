# Starflow @提及交互修复

本补丁只新增客户端提及体验及相应样式，不修改任何数据库、认证资料、后台通知触发器或帖子表。

## 操作
- 在首页编辑器、回复编辑器输入 `@`，展示当前已注册且可查询的账号；继续输入英文用户名进行筛选。
- 点击候选账号自动填入 `@用户名 `，保留光标前后的其他文字，原来的 React 受控发布编辑器继续负责正式提交。
- 新旧帖子正文中的 `@用户名` 自动显示为可点击链接，目标为 `/profile/用户名`。
- 若手动输入不存在的用户名，点击将进入对应的不存在账号页面；本版本不宣称所有手输提及都经过身份确认。

## 边界
- 后端提及通知尚未实装，本补丁不生成或声称生成提及通知。
- 文本末尾的已发布提及链接针对帖子详情/首页的 `.post-content` 生效，避免在整个帖子为链接的探索结果中制造嵌套锚点。
- 不改动现有点赞、转发、关注及回复业务流程。

## 检验
构建后，分别在 iPhone Safari 的首页新动态和帖子回复区测试输入 `@`、搜索 `star`、点选 `@starflow`、发送后点击文字跳转。
