# Starflow AI · X 风格参考包首批 UI/UX 改造（阶段 1）

本更新依照用户上传的 `X_UI_Full_Guide.pdf`、`X_UI_10_Visuals.pdf`、`X_UI_Full_Guide.docx`、`X_UI_COMPLETE.zip` 中的原创设计示意。该参考包的验收重点是桌面、手机浏览器、账号编辑第一屏、帖子交互。**这里是现有网站的增量改造，不是 X 的网站或服务端克隆，也不是完整验收全部 24 章。**

## 本批改动

1. `app/starflow-reference-v2.css`：统一桌面三栏、平板图标导航/双栏、手机单列；小间距帖子流；统一粉紫品牌及 3:1 主页封面；手机安全区及触控尺寸；相册编辑抽屉样式。
2. `components/StarflowProfileEditor.tsx`：在**自己的**个人主页点击原有「编辑资料」按钮，电脑显示编辑弹窗、手机显示全屏编辑页。封面相机和头像相机位于顶部，第一屏可见，显示名/用户名/简介随后排列。保存走现有 Supabase 会话和行级授权；其他用户无法触发编辑。
3. 原图不超过 20 MB，选择后本地预览、水平/垂直裁剪位置可调。点击「保存」才上传，经 Canvas 输出为头像 1:1、封面 3:1 JPG；最终大小不超过 5 MB，继续写入现有存储桶与 `profiles.avatar_url`。提供取消、未保存确认、恢复默认头像/封面及写入失败反馈。
4. `components/StarflowMobileCompose.tsx`：iPhone/Android 单列视图左下角「写动态」按钮，直接聚焦现有发帖框，跨页面使用原有首页业务组件。
5. `app/layout.tsx`：保留现有 `StarflowDiscovery`、`StarflowProfileEnhancements`、`StarflowProfileMedia` 三组件，另外增加这两项 UI 组件与样式，设置 `viewport-fit=cover`。

## 维护既有功能和重要约束

- **没有**数据库迁移，不修改帖子、关注、收藏、点赞、认证审核规则；不触碰已有 Supabase 数据。用户之间的私信继续关闭，`/messages` 仍保持原业务约定。AI 客服、AI 助理不变。
- 正常主页的头像/封面点击仍由原 `StarflowProfileMedia` 提供图片预览；此批把「编辑资料」变为编辑弹窗/全屏编辑页。设置页原有图片管理功能作为备用入口保留。
- 设计参考包中的“私信/聊天”章节与 Starflow 原有的**禁用用户私信**需求冲突，因此刻意不实现。参考图使用原创示意，品牌使用 Starflow 自身粉紫色。
- 当前 `profiles` 表无「城市/网站」列；不虚构持久化。位置与网站字段需要单独批准数据库变更后再实施。

## 验收清单（手动验收必须完成）

- PC ≥1200px：导航/信息流/发现推荐三栏；700–1199px：折叠导航，中栏独立；≤699px：单列/底部导航/左下角发帖按钮。
- 本人个人主页 → 「编辑资料」：直接看到封面及头像两相机入口，首次不滚动即可操作；桌面弹窗、手机全屏。
- 选择头像 → 预览/裁剪 → 保存 → 刷新 → 头像跨设备持久显示。
- 选择封面 → 预览/裁剪 → 保存 → 刷新 → 主页封面持续显示。
- 退出未保存界面有提示；上传失败显示错误；他人主页仍无编辑按钮。
- 首页原有纯文字发帖/媒体/投票，帖子详情/回复/点赞/转发/收藏，认证三色、AI 客服和 AI 助理、粉丝/关注统计功能需重新回归测试。
- 320/360/390/430px，iPhone Safari、Android Chrome 以及桌面浏览器验证无横向溢出。

## 后续阶段：仍未在本批交付

- 帖子详情的引用转发与分享、浏览次数；搜索建议/话题分类；通知分类；草稿与多媒体重试；真正的分页/加载更多；暗色模式；按需独立路由和更完善的图片缩放裁剪交互。
- 这些工作需要在当前 UI 上线测试并定位缺陷后分批完成，不能仅凭 CSS 宣称功能完成。

## 安装与回滚

将此 ZIP 放在仓库根目录，文件名**必须完全是** `starflow-release.zip`，替换旧文件后才会触发仓库现有 GitHub Actions：校验 ZIP → TypeScript → Next.js Build → 自动提交源码 → Cloudflare Build。若失败，保持上一版源码；无数据库回滚操作。

本地做了 TSX 解析、CSS 解析、ZIP 安全结构检查。没有本地全量 npm install / 生产 Supabase 实测，本包提交后须观察 Actions 与生产网站再宣布发布成功。
