# Starflow 本地视频工作台｜零预算可执行功能

此分支添加 `/starflow-video-editor.html`，且从 `/ai-studio` 和 Starflow 菜单可进入。**该页面只使用浏览器内置 API；不会上传素材或自动购买/调用任何模型 API。**

## 已实装的浏览器功能

| 类别 | 功能 | 边界 |
|---|---|---|
| 图片动态成片 | 上传 JPG/PNG/WebP，设置 5–60 秒，平移/推拉动态 | 基于 Canvas 动画，不是生成模型 |
| 本地视频处理 | 导入 MP4/MOV/WebM、裁剪时间、调速、预览 | 取决于浏览器解码能力；导出不含原音轨 |
| 视觉编辑 | 竖屏/横屏/方形裁切、电影/暖色/黑白滤镜、添加单行字幕 | 不具备生成式视频物体替换 |
| 截图 | 导出当前预览的 PNG | 预览分辨率；非源图原画输出 |
| 视频导出 | MediaRecorder + Canvas captureStream，按设备支持度导出 MP4 或 WebM | iOS Safari 的 MediaRecorder/Canvas captureStream 支持和录制效果不保证 |
| 输出目标 | 720P、1080P、4K（实验）；24/30/60/120 FPS（实验） | 输出尺寸和采样目标不等于真正原生 4K / 稳定 120FPS |
| 数据与费用 | 上传本地素材后在浏览器内渲染，无第三方 API 请求 | 页面首次访问与下载网站本身仍依赖网络 |

## 尚未实现 / 不得宣传为已完成

- 真正由自主视频基础模型生成的真人级文生视频与图生视频；
- 视频逐帧动作复刻、换脸与人物跨镜头身份一致性；
- AI 一句话精准局部替换/编辑视频；
- 4K 原生 AI 生成、真实稳定 120FPS 编码、复杂电影级音画同步；
- 大规模自有视频模型训练与收费/大规模公开推理基础设施。

这些能力不能仅靠零预算、iPhone 和前端代码完成。现有 AI Studio 的付费模型服务仍由管理员的开关 `STARFLOW_CREATIVE_ENABLED` 和服务器密钥 `FAL_KEY` 控制，本 PR **不启用、不添加任何密钥**。

## iPhone 验收路径（发布后）

1. Safari 打开 Starflow → AI 工作室 → 免费本地视频工作台。
2. 选择一张你有权使用的 JPG/PNG，填写字幕，选择“慢速推进”，先试 720P / 30FPS 导出。
3. 点击“保存成品视频到 iPhone”。若 Safari 不支持录制，页面应显示兼容性提示，不能伪造成功。
4. 使用 iPhone 拍摄的视频（建议 H.264 MP4）测试时长裁剪、滤镜、变速，确认**无音轨**是当前限制。
5. 最后才尝试 4K/120FPS，先检查实际导出帧率/像素尺寸是否与预期相符。
