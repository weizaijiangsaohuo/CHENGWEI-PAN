## 3. 技术架构及安全边界
- 前端：Next.js 15 + TypeScript + React 19；组件化品牌设计系统；CSS 适配 1440×900/390×844 及 360×800、430×932、768×1024；交互需含普通/加载/空/错误四态。
- 托管：Cloudflare Workers + OpenNext，预览分支与主分支隔离；构建成功 ≠ 业务验收通过。
- 后端：Supabase Auth、PostgreSQL + RLS、Storage、SQL 迁移、Edge Functions。严格区分 `starflow-staging` 与正式 Supabase 项目。
- 实时：消息和通知采用有权限边界的数据库变更订阅或授权轮询，含断线重连、分页、未读持久化。
- 搜索：先实现有索引的帖子/账号查询和用户选择，再分期规划话题热榜及检索服务。
- 管理后台：数据库侧平台管理员角色、最小权限、审核日志；不允许普通用户自行升权，也不能将 service_role 暴露给浏览器。
- 视频与媒体：分存储桶、用户 UID 路径隔离、内容类型/容量校验、清理与 CDN；视频转码另行评估。
- 安全：RLS、恶意越权请求、鉴权/限流、密钥管理、软硬删除和备份恢复演练；商业上线前必须完整审计。
- 品牌：使用用户最终确认的星流原始图，不拿旧图标替代；用户上传的品牌图等素材仅用于自主产品。
