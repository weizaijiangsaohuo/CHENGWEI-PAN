# Starflow 首页轻盈瀑布流 UI 更新（2026-10-11）
用户提供的 20.33s、512×1112 手机录屏展示了小红书网页版首页的双列图卡、横向兴趣分类、底部固定导航及抽屉菜单。此次只借鉴信息密度、视觉节奏、手势响应；Starflow 维持原创品牌图形和现有社交数据，不复制小红书资源/内容。

## 此次设计取舍
- 首页默认「发现卡片」，另提供「经典动态」保留 X 式长帖子/全部互动功能。
- 发现卡片只渲染实际 Supabase posts 数据，封面优先真实图片，其次视频；纯文本使用品牌渐变文字卡片，不捏造封面。
- 关注、点赞、收藏、评论入口照用既有 DB 写操作和单帖详情，独立页面保留转发、举报、长评论。
- 顶部兴趣类目按帖子文本关键字或真实媒体类型过滤，不宣称全站热门榜、AI 推荐模型、个性化广告算法。
- 原生浏览器滚动和惯性优先：CSS columns 双列手机，宽屏三列，横向分类使用原生 overflow-x:auto。无阻断性的 wheel/touchmove 事件，没有强制全页 snap。
- 每批最多初显 16 条，IntersectionObserver 增量展示到本次查询获取的 80 条，非服务端游标分页。真正无限翻页属于下一阶段。
- 点击反馈采用轻量 CSS :active transform，键盘可操作和 prefers-reduced-motion 优先。
- 录屏还有右侧菜单与底部导航，新体验优先保留 Starflow 原已有功能入口；不虚构微信/小红书扫码登录。
- 所有改动仅在 GitHub PR #2 的测试预览分支；未改正式环境，不动邮件验证。

## 验收
- [ ] 手机 iPhone Safari 双列无横向滚动、标签可横滑、图卡点开真实帖子、返回保留阅读位置。
- [ ] 点赞/取消点赞/收藏/评论实测数据库变化和账号权限。
- [ ] 无图帖子展示真实文本；无数据有诚实空态而非示例内容。
- [ ] 「经典动态」支持原全部帖文功能、发帖入口清晰可用。
- [ ] 390×844、360×800、768×1024、1440×900 页面适配和低性能设备性能检查。
- [ ] 不以 CSS 动画模拟流畅：需真机验证长列表滚动、图片加载抖动、WebKit 惯性。
- [ ] 当前仅 80 条 client-side 分批呈现，尚未实现无限滚动/真实推荐排序/图片自动转码。
