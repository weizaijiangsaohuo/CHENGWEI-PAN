No production changes. Existing site design remains the source of truth; do not replace its pages with the lab UI. Map existing login, security settings, inbox, notices, and moderation UI to reviewed v2 API behind a disabled server-side rollout switch only after actual integration tests. Never send legacy credentials to new provider or mix sessions. The environment example is a proposal, not active variables. Owner must create and control free Neon, Brevo, Cloudinary and eligible Didit accounts, confirm free-only limits and provide secrets directly via Cloudflare dashboard, never in GitHub or chat. Neon must be verified with separate restricted credentials and production-compatible driver; no deployment without valid backup or explicit new-data approval. Current proof generation for administrators remains blocked until actual fresh TOTP ceremony is bound to session and one-time action. Virtual WebAuthn test uses real signed ECDSA assertion but no iPhone or real hardware; actual device enrollment and login acceptance required. No Live Didit request, media traffic, mail or paid services.
