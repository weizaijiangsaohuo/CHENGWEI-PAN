# Review gateway and realtime registry: isolated integration only
Dedicated NOLOGIN review role can execute only the reviewed queue/hide/dismiss functions and explicit subject resolver. Trusted server supplies actual session ID; client can submit proof ID but cannot mint proofs, set actors, or assign roles. Endpoint uses fixed same-origin POST, bounded JSON and no-cache response. Test MFA proof is synthetic, not a real issued TOTP credential; do not deploy until real issuer and authorization review. Realtime registry is in-process, accepts only trusted grant and revalidate callback, short expiry, bounded connection count and targeted content-free hints. Actual WebSocket server, Cloudflare Durable Object storage/hibernation, revocation propagation and real network tests are not implemented. No new service resources or billable APIs; existing website layout unchanged.
