# Notification, reconnect and recovery lab
Private inbox notices generated transactionally with message insert, recipient-only RLS, hidden after blocks, server stamped acknowledgements. No push dispatch or external delivery. Staff review queue returns only report ID/reason/time, requires one-time session-bound proof for queue purpose, still owner-only until actual trusted MFA verification is wired. Password reset test uses in-memory captured token only, no email API. New socket policy validates exact HTTPS origin, authenticated verified subject and server-resolved binding, short expiry and generic sync hints; not a WebSocket transport. A future free-plan SQLite Durable Object using WebSocket Hibernation may deliver generic hints, but must verify plan, enforce per-user/aggregate connection limits, reauthorize every hint and sync, and fail closed on revoked sessions; no broadcasts of private data. Do not enable any billing or provision resources now. See https://developers.cloudflare.com/durable-objects/platform/pricing/ and https://better-auth.com/docs/authentication/email-password. No live migration: require owner-controlled accounts and lawful export, recovery/reclaim approval, restoration drill, dependency audit, verified production build before removing old secrets. All previous source preserved.
