# Trusted auth-to-business bridge — lab only
Existing Better Auth test exercises actual signup, verification, password login and revoked session without sending mail. This bridge uses auth.api.getSession and requires verified email plus matching server session subject. Explicit subject-to-principal bindings only; unknown accounts fail closed. No automatic legacy account linking or founder rights. Dedicated non-superuser NOINHERIT login is tested for transaction-local role and actor reset. GUC identity remains safe only with trusted server SQL; do not expose arbitrary SQL. No public route or actual Neon connection. In the future use separate credentials for auth tables, gateway and migration owner; provision new principal through reviewed verified-signup transaction and retain manual proof of ownership for old accounts.
