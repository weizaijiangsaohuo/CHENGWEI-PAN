Rotate disclosed preview credentials securely before activating features. Production cutover remains blocked until independent acceptance and a verified backup/rollback.

An optional separately configured owner key is read exclusively from the process environment and sent only to the hard-coded existing preview readiness URL. This script supports owner-key mode only; Access-protected previews need their separate authorized browser acceptance. Successful checks prove guarded connectivity only, not the deployed SHA, provider integrations or production readiness. Unit fixtures run in UI CI, with no live network or credentials. No deployment, write requests or new Worker.
