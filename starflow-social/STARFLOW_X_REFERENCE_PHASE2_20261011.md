# Starflow AI · X 风格参考包第二阶段：搜索、通知与帖子分享

## 目标与范围

基于已上线的第一阶段页面，继续参考用户上传的《X 风格社交网站 · 全平台 UI 设计规范》及 10 张原创标注示意图。本批**只做增量改造**；保留 Starflow 原创粉紫品牌，不恢复用户之间的私信或聊天入口。

### 本批新增

1. **探索 / 搜索**：手机和桌面统一搜索框，提供「全部、用户、帖子、话题」分类。用户和帖子从原有 Supabase 表实时读取；帖子列表点击跳转原来的完整互动页面。用户搜索支持用户名、昵称；话题列表从最近最多 150 条公开原创帖子统计，不宣称是全站实时热搜。
2. **通知**：提供「全部、未读、提及」三种筛选和「全部已读」。仍读取现有 `notifications` 表，根据授权用户 ID 查询与标记已读。提及筛选**只展示数据库已经产生的 `kind='mention'` 记录**；本包未增加服务器提及识别和推送触发逻辑。
3. **帖子详情**：在现有回复区后补充「写回复、分享帖子、复制链接」按钮。分享优先调用手机浏览器原生分享面板，不支持时使用复制链接；点赞、评论、转发、收藏继续走原有 `SocialApp` 的真实写入逻辑，不复制实现。
4. **响应式**：手机单列，底部导航保留，触控按钮具有较大的点击区域；桌面继续使用现有布局。

### 本包文件

- `starflow-social/components/StarflowDiscoveryPhase2.tsx`：搜索 / 通知 / 帖子详情的增量交互组件。
- `starflow-social/app/starflow-discovery-phase2.css`：隔离的响应式样式，保留 Starflow 品牌。
- `starflow-social/app/layout.tsx`：保留第一阶段所有现有导入和 React 挂载，仅追加第二阶段样式与组件。
- `starflow-social/STARFLOW_X_REFERENCE_PHASE2_20261011.md`：本说明。

### 保留与安全约束

- 无数据库变更，无 Supabase RLS 改动，无数据删除，现有账号 / 帖子 / 关注 / 三色认证 / AI 服务不受业务逻辑改写。
- 不做用户间私信，`/messages` 原有规则不变。
- 账号徽章仅显示已批准的数据库记录。
- 探索显示的是当前公开可读的帖子，不展示草稿或权限外内容。
- 本批不会伪造浏览量、推荐热度或提及通知，也不会把近期样本标作实时热搜。

### 测试清单

1. 首页发帖成功后，进入探索搜索关键词，可以找到帖子；点击结果，进入原帖并进行回复。
2. 探索搜索用户名 / 昵称，能够查看相关账号；输入 `#` 话题可找到匹配帖子。不同分类的结果展示正确。
3. 通知「全部」「未读」切换；对一条未读通知点开后，返回看是否标记为已读；「全部已读」后重新进入，状态持久保存。
4. 「提及」只在后台存在真正提及记录时出现，空状态不等于故障。
5. 帖子详情点击「分享帖子」应弹出原生分享菜单（如系统支持）；「复制链接」后可粘贴访问。
6. 手机 320/360/390/430px、iPhone Safari、电脑浏览器检查无横向滚动、弹层或底部按钮遮挡。
7. 回归首页发帖、点赞、回复、收藏、个人主页编辑、粉丝统计、封面裁剪、AI 客服。

## 已知限制

- 搜索尚无全站索引或分页：帖子搜索最多返回最近 60 条匹配结果，用户最多 28 条去重，话题样本最多 150 条原创帖子；不是无限滚动，也不是全站规模精确搜索。
- 通知一次最多加载最近 100 条。原 SocialApp 的菜单未读数直到重新加载时可能延迟刷新。提及提醒的**生成机制**不在此包实现范围内。
- 普通帖子引用转发、浏览量、推送、完整层级评论、多媒体上传失败重试属于后续单独开发。
- 文件通过离线 TSX 语法、CSS 解析与 ZIP 结构测试；线上 TypeScript / Next.js 构建和实际功能，必须在 GitHub Actions 与浏览器验收后方能宣布通过。
